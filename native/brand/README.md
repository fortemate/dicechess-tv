# Brand inputs

Verbatim copies from `fortemate/brand`, `dist/identity/web/`. **Do not edit
them and do not redraw the mark here.** Regenerating it is that repository's
job; `BRAND.md` there is the authority, and it forbids the variations that
suggest themselves — no wordmark lockup while the typography is provisional,
and the mark never goes inside a die, a board or another grid.

| File                           | Used for                                                |
| ------------------------------ | ------------------------------------------------------- |
| `pwa-maskable-512.png`         | the application icon, copied to `assets/image/icon.png` |
| `fortemate-mark-512-white.png` | the splash frame, composited on the board's background  |

The icon is the **maskable** export rather than the plain mark, and that is the
point: the Fire TV launcher does not show a square. It draws a wide tile and
fits the icon into it, so a bare mark on transparency came out distorted. A
maskable icon is built for exactly this — an opaque tile with the mark at about
52 % of the canvas, inside an 80 % safe zone — so the launcher can crop it
however it likes without cutting the mark. `BRAND.md` also settles the colour:
tiles use pure black, which suits a television and matches Amazon's advice that
light solid icons read best in Settings.

These files live outside `assets/` on purpose. Everything under `assets/` is
generated by `scripts/generate-splash.mjs` and packaged; the splash source is
not, and should not be shipped twice.
